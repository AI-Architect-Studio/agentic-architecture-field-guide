# AI Architect client delivery pack

Deliver a system decision another engineer can inspect and a client can operate. This pack takes one support/knowledge-agent project from a bounded brief to acceptance criteria, implementation evidence, recovery and handover.

The pack is an editable MIT companion to the Agentic Architecture Field Guide. It includes a fictional worked dossier and reusable templates. No customer deployment, commercial offer or certification is established by these files.

## A useful first delivery

Start with one tenant, one approved corpus and one operator job. A client support specialist should receive a draft, its source references and a clear escalation reason when the answer is unsupported. Refunds, account changes and outbound sending remain outside this first project.

Copy the templates into the client's private project directory. Keep one canonical architecture decision and reference it from every other file. Retain the failed trial alongside the corrected implementation and subsequent trial. The receiving engineer must be able to reconstruct the decision without the original chat.

The pack's completion condition is an independently inspected handover package with a recorded owner decision. A populated template or a passing imported-evidence check is preparation for that decision.
